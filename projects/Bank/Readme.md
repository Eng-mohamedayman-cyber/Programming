# 🏦 Bank Management System – C++

A console-based **Bank Management System** developed using C++ as part of my practical learning journey with **Programming Advices**.

## 📌 Project Overview

This project is a simple bank client management system that allows users to manage client records through an interactive console menu.

Client information is stored in a text file, allowing data to persist after the program is closed.

## 🎯 Features

* Show all clients
* Add new clients
* Delete clients
* Update client information
* Find clients by account number
* Prevent duplicate account numbers
* Display client information
* Confirmation before deleting or updating
* Save and load client data from a file
* Interactive main menu

## 📂 Data Storage

The application uses a text file:

`Client.txt`

Each client record is stored as a single line, with fields separated by:

`#//#`

The program converts between text records and C++ structures when reading and writing data.

## 🔄 CRUD Operations

The project implements the main CRUD operations:

* **Create** → Add new clients
* **Read** → Display and find clients
* **Update** → Modify client information
* **Delete** → Remove clients
