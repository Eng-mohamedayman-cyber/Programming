# 🏦 ATM System — C++

A console-based **ATM System** developed using C++ to simulate essential banking operations while applying practical programming concepts such as file handling, data structures, authentication, validation, and persistent data management.

## 🚀 Features

* 🔐 Account Number & PIN Authentication
* 💸 Quick Withdrawal
* 💵 Normal Withdrawal
* 💰 Deposit
* 📊 Check Balance
* 🚪 Logout
* 👤 Client Data Management
* 💾 Persistent Data Storage
* ✅ Transaction Validation

## ⚙️ How It Works

The system loads client information from a text file and uses the account number and PIN to authenticate the user.

After successful authentication, the user can access the ATM main menu:

1. Quick Withdraw
2. Normal Withdraw
3. Deposit
4. Check Balance
5. Logout

Transactions update the client's balance and save the updated data back to the file.

## 📂 Data Storage

Client information is stored in:

`Client.txt`

Each client record contains:

* Account Number
* PIN Code
* Name
* Phone Number
* Account Balance
