# 🧠 Math Quiz Game – C++

A console-based **Math Quiz Game** developed using C++ as part of my practical learning journey with **Programming Advices**.

## 📌 Project Overview

The Math Quiz Game generates random mathematical questions based on the user's selected difficulty level and operation type.

The player can choose the number of questions, difficulty level, and mathematical operation. The program then generates questions, checks the player's answers, tracks the score, and displays the final quiz result.

## 🎯 Features

* Choose the number of questions
* Choose question difficulty:

  * Easy
  * Medium
  * Hard
  * Mixed
* Choose operation:

  * Addition
  * Subtraction
  * Multiplication
  * Division
  * Mixed
* Random question generation
* Automatic answer correction
* Correct and incorrect answer tracking
* Pass/Fail result
* Colored console feedback
* Replay option
